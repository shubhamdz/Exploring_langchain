# Exploring LangChain

Welcome to my LangChain exploration repository! This project serves as a personal learning space where I push my progress, experiments, and examples while learning [LangChain](https://python.langchain.com/).

## Repository Structure

Here's an overview of the concepts covered so far:

- **1.LLM**: Basic integration with Large Language Models.
- **2.ChatModels**: Working with Chat Models (Google Gemini, Hugging Face, OpenAI, Anthropic).
- **3.EmbeddedModels**: Generating embeddings and calculating document similarity.
- **prompt**: Crafting and managing prompts, message placeholders, and prompt templates.
- **langchain_structured_output**: Extracting structured output using TypedDict, Pydantic, and JSON schemas.
- **output_parsers**: Utilizing String, JSON, Structured, and Pydantic output parsers.
- **chains**: Building Simple, Sequential, Parallel, and Conditional chains.
- **runnables**: Exploring the LangChain Expression Language (LCEL) and custom runnables.

## Setup & Installation

To run the examples in this repository, you'll need to install the dependencies listed in `requirements.txt`. 

1. Clone the repository:
```bash
git clone https://github.com/shubhamdz/Exploring_langchain.git
```
2. Install the required packages:
```bash
pip install -r requirements.txt
```
3. Create a `.env` file in the root directory and add your API keys:
```env
HUGGINGFACEHUB_API_TOKEN=your_huggingface_token
GOOGLE_API_KEY=your_google_api_key
```
